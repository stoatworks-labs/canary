# CANary rev A — JLCPCB package

Upload these three:

| File | Where it goes |
|---|---|
| `canary-jlcpcb-gerbers.zip` | the gerber upload on the PCB order page |
| `canary-jlcpcb-bom.csv` | **BOM file** on the assembly page |
| `canary-jlcpcb-cpl.csv` | **CPL file** on the assembly page |

Also here: `canary-jlcpcb-designators.csv` (designator/quantity list) and
`canary-jlcpcb-netlist.ipc` (IPC-D-356, optional — lets JLC electrically test
the bare board).

Board parameters for the order form are in [`../../../docs/FAB.md`](../../../docs/FAB.md#board-specification).

## Provenance

Generated by the **JLC Fabrication Toolkit** KiCad plugin, run headless against
the board's own `pcbnew` bindings, so JLCPCB's conventions are inherited rather
than guessed. In particular the **rotations carry the plugin's correction
database** (`transformations.csv`), which is maintained from real assembly
feedback.

That correction is why this package is not interchangeable with `../generic/`,
which uses un-corrected KiCad-native angles. Do not mix files
between the folders.

## Hand-fit parts

JLCPCB will not fit the etherCON connectors (J201, J202, J401), the 1.27 mm
header (J301) or the DIP switch (SW201). They appear in the BOM and CPL so the
two stay in parity with the board — **mark them Do Not Place at review**.

## Regenerating

Via the plugin, not `fab_package.py` — see `hardware/scripts/run_vendor_toolkits.py`.
`fab_package.py` deliberately leaves this folder alone.
